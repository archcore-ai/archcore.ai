### Archcore + Ponytail

Applies when the session shows Ponytail mode or a `ponytail` skill.

1. Before a ladder rung or a `/ponytail-review` finding, call `search_documents` with `content` naming the affected symbols.
2. If an accepted Archcore record requires the code, keep it and cite the record path.
3. When the request states a decision the owner settled (adopt, drop, replace or defer something), record it in a draft `adr` before reporting the task complete.
4. Create every new `.archcore/**/*.md` record with status `draft`.
